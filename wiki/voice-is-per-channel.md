# Voice is per channel, not per brand

A tool that learns a voice from examples turns the interesting question into *which examples*,
and the intuitive answer — ours — is wrong.

The LinkedIn voice is not the Instagram voice. They differ in length, in how much throat-clearing
survives, in whether a joke lands or reads as unserious, and none of that is captured by anything
a brand would call its tone of voice. So the example set is assembled per channel. "Our voice" is
not one asset trained once and reused everywhere; it is several, one per place you publish.

The failure this prevents is a quiet one, which is why it is worth stating. Feed the wrong set and
nothing looks broken. The copy is fluent, it is recognisably the brand, it passes any check that
asks whether it sounds like us — and it is wrong for where it is going, in the way a press release
posted as a comment is wrong. There is no error to catch, only a mismatch between register and
venue that the tool has no way to notice because you never told it which venue it was writing for.

The practical consequence reorders the work. Curating examples is the job; writing the prompt is
not. That sits badly with the instinct to solve a text problem by writing better text, but it is
the same trade the whole lecture keeps making — supply the material, do not describe it.
